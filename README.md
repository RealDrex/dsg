## ⌨️ الأوامر: عربي، بالسلاش أو بالبريفكس

كل الأوامر أسماءها عربية، وكل أمر يشتغل بطريقتين:

| بالسلاش | بالبريفكس (الافتراضي `!`) |
|---|---|
| `/باند العضو:@فلان السبب:سبام` | `!باند @فلان سبام` |
| `/تذكرة إغلاق` | `!تذكرة إغلاق` |
| `/حماية وايت_ليست إضافة الهدف:@الإدارة` | `!حماية وايت ليست إضافة @الإدارة` |

- **تغيير البريفكس:** `/البريفكس` أو من لوحة التحكم ← إعدادات البوت. منشن البوت يشتغل كبريفكس بعد.
- البريفكس يقبل الكتابة بدون همزات (`!اخفاء` = `!إخفاء`) والأسماء الإنجليزية (`!ban`).
- إذا نسيت جزء من الأمر، البوت يرد عليك بطريقة الاستخدام الصحيحة.
- أوامر الإدارة بالبريفكس تتحقق من نفس صلاحيات السلاش.

## 🖥️ لوحة التحكم (الموقع)

`/dashboard` — تسجيل دخول بديسكورد، وبعدها قوائم لكل بلوقن تعدل منها كل الإعدادات:
رومات اللوقات، رسائل الترحيب، الحمايات، رتب المكافآت، أنواع التذاكر، الردود التلقائية، البريفكس… وأزرار جاهزة مثل **إرسال بانل التذاكر** و**إنشاء رومات اللوقات** و**إنشاء الألوان**.

- يقدر يدخل أي أحد عنده صلاحية **Manage Server** في السيرفر (أو آيديه في `OWNER_IDS`).
- كل قيمة تتحقق في السيرفر قبل الحفظ (الرومات والرتب لازم تكون موجودة فعلاً).

**تفعيلها:**
1. من Developer Portal ← OAuth2: انسخ **Client Secret** وحطه في `CLIENT_SECRET`.
2. في نفس الصفحة ← **Redirects** أضف: `http://localhost:3000/auth/callback` (أو `<رابط موقعك>/auth/callback`).
3. إذا الموقع على دومين، حط الرابط في `PUBLIC_URL`.

## 🚀 التشغيل

### 1) سوّ البوت في ديسكورد
1. ادخل [Discord Developer Portal](https://discord.com/developers/applications) ← **New Application** ← سمّه `Sword`.
2. من **Bot**: انسخ التوكن، وحط صورة البوت `assets/logo-round.png`.
3. فعّل الـ **Privileged Gateway Intents**: `Server Members` و `Message Content`.
4. من **OAuth2 → URL Generator**: اختر `bot` + `applications.commands` وصلاحية `Administrator`، وادخل البوت سيرفرك.
5. **مهم:** ارفع رتبة البوت لأعلى الرتب في السيرفر.

### 2) جهّز المشروع (يحتاج Node.js 22.5 أو أحدث)
```bash
npm install
cp .env.example .env     # عبّي DISCORD_TOKEN و CLIENT_ID و CLIENT_SECRET و GUILD_ID
npm run check            # يتأكد إن كل الأوامر العربية سليمة
npm test                 # اختبارات البريفكس والترجمة
npm run deploy           # يسجل الأوامر في سيرفرك
npm start                # يشغل البوت + الموقع + لوحة التحكم
```

الموقع: `http://localhost:3000` • لوحة التحكم: `http://localhost:3000/dashboard`

> إذا كنت مسجل الأوامر الإنجليزية من قبل، `npm run deploy` يستبدلها بالعربية تلقائياً.

## 🗂️ هيكل المشروع

```
assets/              شعار Sword والبانرات وخط السيف
src/
  index.js           تشغيل البوت
  deploy.js          تسجيل الأوامر
  core/              الثيم، قاعدة البيانات، الإعدادات، تحميل البلوقنات
    i18n.js          الأسماء العربية للأوامر
    prefix.js        أوامر البريفكس
  plugins/<name>/    كل بلوقن في مجلد مستقل (أوامر + أحداث + أزرار)
  web/               الموقع ولوحة التحكم (Express)
scripts/check.js     فحص كل الأوامر بدون اتصال بديسكورد
scripts/test.js      اختبارات
```

**إضافة بلوقن جديد:** سوّ مجلد في `src/plugins/` فيه `index.js` يصدّر `{ id, name, nameAr, emoji, description, defaults, commands, events, components, dashboard, actions }` — ويظهر تلقائياً في `/مساعدة` و `/البلوقنات` والموقع ولوحة التحكم. الأسماء العربية للأوامر الجديدة تنضاف في `src/core/i18n.js`.

البيانات محفوظة في `data/sword.db` (SQLite مدمج في Node، ما يحتاج تثبيت شي).
