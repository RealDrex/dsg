## الأوامر: عربي، بالسلاش أو بالبريفكس

كل الأوامر أسماءها عربية، وكل أمر يشتغل بطريقتين:

| بالسلاش | بالبريفكس (الافتراضي `!`) |
|---|---|
| `/باند العضو:@فلان السبب:سبام` | `!باند @فلان سبام` |
| `/تذكرة إغلاق` | `!تذكرة إغلاق` |
| `/حماية وايت_ليست إضافة الهدف:@الإدارة` | `!حماية وايت ليست إضافة @الإدارة` |

- **تغيير البريفكس:** `/البريفكس` أو من لوحة التحكم ← إعدادات البوت. منشن البوت يشتغل كبريفكس بعد.
- البريفكس يقبل الكتابة بدون همزات (`!اخفاء` = `!إخفاء`) والأسماء الإنجليزية (`!ban`).
- إذا نسيت جزء من الأمر، البوت يرد عليك بطريقة الاستخدام الصحيحة.
- أوامر الإدارة بالبريفكس تتحقق من نفس صلاحيات السلاش.

## لوحة التحكم (الموقع)

`/dashboard` — تسجيل دخول بديسكورد، وبعدها قوائم لكل بلوقن تعدل منها كل الإعدادات:
رومات اللوقات، رسائل الترحيب، الحمايات، رتب المكافآت، أنواع التذاكر، الردود التلقائية، البريفكس… وأزرار جاهزة مثل **إرسال بانل التذاكر** و**إنشاء رومات اللوقات** و**إنشاء الألوان**.

- يقدر يدخل أي أحد عنده صلاحية **Manage Server** في السيرفر (أو آيديه في `OWNER_IDS`).
- كل قيمة تتحقق في السيرفر قبل الحفظ (الرومات والرتب لازم تكون موجودة فعلاً).

**تفعيلها:**
1. من Developer Portal ← OAuth2: انسخ **Client Secret** وحطه في `CLIENT_SECRET`.
2. في نفس الصفحة ← **Redirects** أضف: `http://localhost:3000/auth/callback` (أو `<رابط موقعك>/auth/callback`).
3. إذا الموقع على دومين، حط الرابط في `PUBLIC_URL`.

## التشغيل على خادم ويندوز (bat)

### 1) سوّ البوت في ديسكورد (مرة وحدة)
1. ادخل [Discord Developer Portal](https://discord.com/developers/applications) ← **New Application** ← سمّه `Sword`.
2. من **Bot**: انسخ **التوكن**، وحط صورة البوت `assets/logo-round.png`.
3. في نفس الصفحة فعّل **Server Members Intent** و **Message Content Intent**.
4. من **OAuth2**: انسخ **Client ID** و **Client Secret**، وفي **Redirects** أضف:
   `http://localhost:3000/auth/callback` (أو `https://دومينك/auth/callback` إذا الموقع على دومين).
5. من **OAuth2 → URL Generator**: اختر `bot` + `applications.commands` وصلاحية `Administrator`، وادخل البوت سيرفرك.
6. ارفع رتبة البوت لأعلى الرتب في السيرفر.

### 2) على الخادم
| الملف | وش يسوي |
|---|---|
| **`install.bat`** | يتأكد من Node.js 22.5+، يثبت الحزم، يسوي ملف `.env` ويفتحه لك في Notepad |
| **`start.bat`** | يسجل الأوامر ويشغل البوت + الموقع، و**يرجع يشغله تلقائياً** إذا طفى |
| **`update.bat`** | يسحب آخر تحديث (git pull) ويثبت الحزم |

1. ثبّت [Node.js 22 LTS](https://nodejs.org) (أو أحدث).
2. دبل كليك **`install.bat`** ← عبّي `.env` (التوكن، `CLIENT_ID`، `CLIENT_SECRET`، `GUILD_ID`) واحفظ.
3. دبل كليك **`start.bat`** — خلاص 

- الموقع ولوحة التحكم: `http://localhost:3000` (البورت من `PORT` في `.env`).
- السجلات تنحفظ يومياً في مجلد `logs\`.
- إذا فيه خطأ في `.env` (توكن غلط مثلاً) الـ bat يوقف ويوريك السبب بدل ما يعيد التشغيل للأبد.
- **تشغيل تلقائي مع الخادم:** Task Scheduler ← Create Task ← Trigger: *At startup* ← Action: `start.bat` (Start in: مجلد البوت) ← فعّل *Run whether user is logged on or not*.
- **فتح الموقع للناس:** افتح البورت في Windows Firewall، وحط رابطك العام في `PUBLIC_URL` وأضف `<PUBLIC_URL>/auth/callback` في Redirects.

<details><summary>تشغيل بدون bat (لينكس / يدوي)</summary>

```bash
npm install --omit=dev
cp .env.example .env     # عبّي القيم
npm run deploy && npm start
```

## تسجيل الدخول بحساب ديسكورد

زر **تسجيل الدخول** في أعلى الموقع يدخلك بحساب ديسكورد (OAuth2 — ما نشوف إلا اسمك وصورتك).
بعد الدخول يطلع اسمك وصورتك فوق، وتقدر تفتح **لوحة التحكم** لأي سيرفر عندك فيه صلاحية *Manage Server*.
الجلسة تبقى 7 أيام، وزر الخروج جنب اسمك.

## الأيقونات

لا إيموجيات — كل الأيقونات SVG من مجموعة [Lucide](https://lucide.dev) بثيم Sword:
- **بالموقع:** SVG مباشرة (`src/web/public/icons.svg`).
- **بالبوت:** نفس الأيقونات كـ PNG (`assets/icons/`)، البوت يرفعها **تلقائياً** كإيموجيات خاصة بالتطبيق (Application Emojis) أول ما يشتغل — ما تاخذ من خانات إيموجي السيرفر، وتظهر في الإمبدات والقوائم والأزرار.
- تبي تضيف/تغير أيقونة؟ عدّل `src/core/icon-list.js` ثم `npm install` و `npm run icons` — البوت يرفع الجديدة لحاله.

## هيكل المشروع

```
install.bat / start.bat / update.bat   التشغيل على ويندوز
assets/              شعار Sword والبانرات وخط السيف
assets/icons/        أيقونات البوت (PNG) المولدة من SVG
src/
  index.js           تشغيل البوت
  deploy.js          تسجيل الأوامر
  core/              الثيم، قاعدة البيانات، الإعدادات، تحميل البلوقنات
    i18n.js          الأسماء العربية للأوامر
    prefix.js        أوامر البريفكس
  plugins/<name>/    كل بلوقن في مجلد مستقل (أوامر + أحداث + أزرار)
  web/               الموقع ولوحة التحكم (Express)
scripts/check.js     فحص كل الأوامر والأيقونات بدون اتصال بديسكورد
scripts/test.js      اختبارات
```

**إضافة بلوقن جديد:** سوّ مجلد في `src/plugins/` فيه `index.js` يصدّر `{ id, name, nameAr, emoji, description, defaults, commands, events, components, dashboard, actions }` — ويظهر تلقائياً في `/مساعدة` و `/البلوقنات` والموقع ولوحة التحكم. الأسماء العربية للأوامر الجديدة تنضاف في `src/core/i18n.js`.

البيانات محفوظة في `data/sword.db` (SQLite مدمج في Node، ما يحتاج تثبيت شي).
